# مفقوداتي الجامعية 🎒

موقع للمفقودات داخل جامعة الجزيرة. يقدر الطالب ينشر غرضاً فقده أو وجده، ويبحث في الأغراض حسب الكلية أو المكان،  وبعد يرجع الغرض لصاحبه تتغير حالة المفقو إلى 
 «تم التسليم لصاحبه».

مشروع مادة **برمجة تطبيقات الإنترنت**.

🔗 **الموقع الحي:** http://yousif-lostfound.xo.je

## التقنيات المستخدمة
- HTML5 و CSS3 و Bootstrap 5 (RTL)
- JavaScript
- PHP مع PDO وprepared statements
- MySQL
- الاستضافة: InfinityFree

## الصفحات
| الصفحة | الوصف |
|---|---|
| `index.php` | الرئيسية |
| `login.php` | تسجيل الدخول |
| `register.php` | إنشاء حساب مع اختيار الكلية |
| `items.php` | عرض الأغراض والبحث والفلترة بالكلية |
| `add-item.php` | إضافة غرض مع صورة (للمسجّلين فقط) |
| `returned.php` | الأغراض التي تم تسليمها لأصحابها |
| `contact.php` | تواصل معنا (الرسائل تُحفظ في قاعدة البيانات) |
| `logout.php` | تسجيل الخروج |

## المميزات
- كلمات المرور مشفّرة بـ `password_hash`
- حماية من SQL Injection باستخدام prepared statements
- الصفحات المحمية تحتاج تسجيل دخول
- شعار الكلية يظهر للمستخدم بعد الدخول
- خيار «مكان آخر» للأماكن خارج الكليات
- صاحب المنشور فقط يقدر يعلّم الغرض «تم التسليم لصاحبه»

## طريقة التشغيل
1. أنشئ قاعدة بيانات MySQL واستورد ملف `database.sql`.
2. افتح `includes/db.php` واكتب بيانات الاتصال بقاعدة البيانات.
3. ارفع الملفات إلى مجلد `htdocs` في الاستضافة.
4. تأكد أن مجلد `uploads/` قابل للكتابة.

## هيكل المشروع
```
lost-found/
├── assets/        (CSS, JS, الخطوط، الشعارات)
├── includes/      (الاتصال بقاعدة البيانات، الهيدر، الفوتر، الحماية)
├── uploads/       (صور الأغراض المرفوعة)
├── database.sql
└── *.php
```
